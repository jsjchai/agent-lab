# 03 · 模型接入与流式接口

> 对应源文档 §5（Spring AI 的 Python 替代）· 代码模块 [`m03_client_sse.py`](../m03_client_sse.py) + [`common/llm.py`](../common/llm.py) · 运行：`../../.venv/bin/python m03_client_sse.py`

## 一、这是什么 / 为什么重要

源文档 §5 讲 Spring AI 的模型接入能力：ChatClient、Structured Output、Streaming、Retry/Timeout、
EmbeddingModel。本模块用 Python 等价物把这些能力落地，并强调一个工程原则——
**业务流程不绑定模型供应商**：把模型调用抽成统一适配层 `common/llm.py`，切换 mock ↔ 真实模型、
换供应商，业务代码一行不改。这正是源文档 §6「不要让业务流程绑定框架专有 API」的体现。

## 二、核心概念详解

### Spring AI → Python 能力对照

| Spring AI | 本项目 | 位置 |
|---|---|---|
| ChatClient / ChatModel | `LLM.chat()` | common/llm.py |
| Structured Output | `LLM.chat_json()` + pydantic | [01](01-LLM基础与结构化输出.md) |
| Streaming / SSE | `LLM.stream()` + FastAPI `StreamingResponse` | m03 |
| Retry / Timeout | openai client `timeout` / `max_retries` | common/llm.py |
| EmbeddingModel | `LLM.embed()` | [06](06-RAG与知识问答.md) |
| Token 统计 | `LLM.stats` | common/llm.py |

### 双后端适配（mock / openai）
`LLM(mode)` 支持 `mock`（离线确定性替身）与 `openai`（任何 OpenAI 兼容接口：OpenAI/DeepSeek/Qwen/vLLM/Ollama）。
mock 让流程可复现可测试；openai 接真实模型。实例级参数 `model/base_url/embed_model/api_key` 支持按请求选模型
（可视化页面的模型选择器即用此能力）。

### SSE（Server-Sent Events）
服务端单向流式推送，适合 LLM 逐 token 输出。格式 `data: {...}\n\n`，结束发 `data: [DONE]`。
相比 WebSocket 更轻量，浏览器用 `EventSource` 或 fetch 流式读取。

### 超时 / 重试 / 异常映射
模型调用必须设超时与重试上限；**不向前端返回原始内部异常**（避免泄漏堆栈/密钥），统一映射为友好错误。

## 三、代码实现解析

### LLM 适配层（common/llm.py）

```python
class LLM:
    def __init__(self, mode=None, model=None, base_url=None, embed_model=None, api_key=None):
        self.mode = (mode or current_mode()).lower()      # mock / openai
        self.model = model or model_name()                # 实例级覆盖，回退环境变量
        self.stats = {"calls": 0, "prompt_tokens": 0, "completion_tokens": 0, "errors": 0}

    def chat(self, messages, temperature=0.0, max_tokens=None) -> str:
        if self.mode == "openai":
            resp = self._openai_client().chat.completions.create(model=self.model, ...)
            # 累计 usage 到 stats
            return resp.choices[0].message.content or ""
        return self._mock_reply(...)                      # 离线确定性替身
```

`_openai_client` 设 `timeout=TEACHING_TIMEOUT(默认120)`、`max_retries=TEACHING_MAX_RETRIES(默认2)`。
`stream()` 在 openai 模式逐 chunk yield，mock 模式把替身输出切片模拟流式。

### build_app：最小 FastAPI 服务

```python
# m03_client_sse.py
def build_app(llm=None):
    app = FastAPI(title="Teaching AI 模型接入示例")

    @app.post("/chat")
    def chat(body: dict):
        try:
            reply = llm.chat([{"role": "user", "content": body.get("text", "")}])
            return {"reply": reply, "stats": llm.stats}
        except Exception:
            return JSONResponse({"error": "模型服务暂时不可用，请稍后重试"}, status_code=503)

    @app.get("/chat/stream")
    def chat_stream(text: str = "你好"):
        def gen():
            try:
                for chunk in llm.stream([{"role": "user", "content": text}]):
                    yield f"data: {json.dumps({'chunk': chunk}, ensure_ascii=False)}\n\n"
                yield "data: [DONE]\n\n"
            except Exception:
                yield f"data: {json.dumps({'error': 'stream interrupted'})}\n\n"
        return StreamingResponse(gen(), media_type="text/event-stream")
    return app
```

设计意图：
- `/chat` 捕获异常 → 503 + 友好文案，**不外泄内部异常**。
- `/chat/stream` 用生成器逐 chunk 推送，结束 `[DONE]`；流中断发 error 事件而非崩溃。
- `build_app(llm)` 注入 LLM，测试时传 mock，生产传真实——依赖注入便于测试。

## 四、工程要点与常见坑

| 现象 | 原因 | 对策 |
|---|---|---|
| 前端拿到原始堆栈/密钥 | 直接抛内部异常 | 捕获后映射为友好错误（503） |
| 模型卡死拖垮服务 | 无超时 | client `timeout` + `max_retries` |
| 流式中途断连 | 网络/模型中断 | gen 内 try/except 发 error 事件 |
| 换供应商要改业务代码 | 调用散落各处 | 统一 `LLM` 适配层，业务只调接口 |
| 单元测试依赖真实模型 | 直接调 API | mock 后端 + `build_app(LLM("mock"))` |
| 中文 chunk 乱码 | JSON 默认 ascii | `ensure_ascii=False` |

## 五、验收与测试

`selftest()` 用 FastAPI `TestClient`（无需起真实服务）：

```python
app = build_app(LLM("mock"))
client = TestClient(app)
r = client.post("/chat", json={"text": "你好"})
assert r.status_code == 200 and "reply" in r.json()
with client.stream("GET", "/chat/stream", params={"text": "你好"}) as resp:
    assert resp.headers["content-type"].startswith("text/event-stream")
    lines = [ln for ln in resp.iter_lines() if ln.startswith("data:")]
assert lines[-1] == "data: [DONE]"          # 流以 [DONE] 结束
assert any("[DONE]" not in ln for ln in lines)  # 确有内容 chunk
```
