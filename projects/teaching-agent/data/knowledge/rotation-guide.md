# 轮转计划说明

## 什么是轮转计划

轮转计划是按周编排的教研组轮值安排，记录每个组织本周的集体备课、听评课、研讨等活动。轮转计划以快照形式提供，供活动创建时参考。

## 如何查询轮转计划

通过 queryRotationSnapshot 工具查询当前用户可访问组织的轮转计划快照。查询时会校验组织权限，无权访问的组织返回拒绝。快照包含周次与本周轮值内容。

## 轮转与活动创建的关系

创建教研活动前，建议先查询本周轮转计划，避免与既有轮值安排冲突。轮转计划只读，不可由 Agent 修改。
