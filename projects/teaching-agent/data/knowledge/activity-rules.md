# 教学活动管理制度

## 活动类型与时长

教学活动分为教研活动、培训、公开课三类。单次活动时长须在 30 分钟到 240 分钟之间。超出时长范围的活动申请将被业务规则校验拦截。

## 主讲人要求

每次活动须安排 1 到 3 位主讲人。主讲人必须属于当前用户可访问的组织范围，跨组织邀请主讲人需要额外审批。

## 时间要求

活动日期须至少提前 1 天申请，当天创建当天的活动不予通过。日期格式支持「X月X日」「YYYY-MM-DD」「周X」「明天」「后天」。

## 创建流程

创建教学活动须经过：意图识别、缺项澄清、查询业务规则、生成草稿、业务规则校验、用户确认，最后由 Teaching 既有业务 API 完成创建。Agent 不直接写业务表。
