# 05 · 规划与推理

**目标**：让 Agent 会把长任务拆开，并知道什么时候该反思、重试、放弃。

## 关键问题
- 先规划再执行（plan-and-execute）和边走边看（ReAct），各自什么时候更合适？
- 子任务怎么定义才算「可验证」？
- 反思（reflection）什么时候有用，什么时候只是浪费 token？
- 怎么防止计划越改越乱？
