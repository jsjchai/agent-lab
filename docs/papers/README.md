## 阅读记录约定

- 每篇论文一个笔记文件：`notes/YYYY-MM-DD-短标题.md`，用 [note 模板](../../templates/note.md)。
- 笔记必须回答三个问题：**它解决什么问题 / 核心做法是什么 / 有没有被后续工作推翻**。
- 只写「我读懂了什么」，不抄摘要。
- 读完更新上表状态：☐ 待读 ｜ ◐ 在读 ｜ ☑ 已写笔记。
