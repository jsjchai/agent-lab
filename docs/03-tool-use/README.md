# 03 · 工具调用

**目标**：不靠框架，亲手跑通一次完整的「模型决定调工具 → 执行 → 回填 → 继续」。

## 关键问题
- 模型是**怎么**决定调哪个工具、传什么参数的？（看 schema，还是看自然语言描述？）
- 工具描述写不好会怎样？参数该由谁校验？
- 工具报错、超时、参数非法时，循环怎么继续？
- MCP 解决了什么问题？什么时候值得上？
