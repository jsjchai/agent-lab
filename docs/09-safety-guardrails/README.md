# 09 · 安全与护栏

**目标**：知道 Agent 会被怎么攻击、会怎么「好心办坏事」，并有一层最低限度的防线。

## 关键问题
- 提示注入（尤其是来自网页、文件、工具返回的间接注入）怎么防？
- 危险工具（写文件、发消息、删数据、花钱）怎么加确认与权限？
- 怎么限制「能访问什么」，而不是只靠 prompt 说「不要做」？
- 出错之后怎么止损、怎么留痕？

## 产出
- [ ] 一次成功和一次失败的工具注入测试（自己构造攻击样本）
- [ ] 危险操作的「人类确认」拦截层
- [ ] 一份权限清单：每个工具能碰什么、不能碰什么
- [ ] 笔记：哪些护栏是 prompt 级（弱），哪些是代码级（强）
