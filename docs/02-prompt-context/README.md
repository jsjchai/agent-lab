# 02 · 提示与上下文工程

**目标**：让模型输出**稳定、可解析、可测试**，而不是「偶尔很惊艳」。

## 关键问题
- 同一个任务，为什么换一种上下文组织方式效果差很多？
- 结构化输出（JSON / schema）怎么保证不崩？崩了怎么兜底？
- 上下文里哪些该给、哪些该藏？token 预算怎么分配？
