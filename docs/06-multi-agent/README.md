# 06 · 多智能体

**目标**：判断「多智能体」什么时候真的比单智能体好，而不是为了架构好看。

## 关键问题
- 角色分工 vs 并行子任务 vs 辩论/评审，三种模式各自解决什么问题？
- 通信靠什么？消息格式、共享状态、还是文件？
- 什么时候会互相甩锅、重复劳动、信息衰减？
- 多一层的成本（token、延迟、调试难度）值不值？

- [ ] 待补充（多智能体框架文档、协作模式综述）

## 产出
- [ ] 一个 2~3 角色的协作实现（含明确的终止条件）
- [ ] 与单智能体版本的对比：分数、token、延迟
- [ ] 一页结论：我在什么场景下**不会**再用多智能体
