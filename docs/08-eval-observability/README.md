## Teaching 场景落地（源文档 §12 评测、监控与质量门禁）

配套可运行示例：[projects/teaching-agent/m08](../../projects/teaching-agent/m08_eval.py) + [golden_set.jsonl](../../projects/teaching-agent/golden_set.jsonl)

Golden Set 覆盖：正常创建、缺项澄清、多轮补充、非法时间/对象、无权限访问、有答案/无答案知识问答、Prompt Injection、模型超时、工具失败、重复消息。文档要求 ≥100 条，本项目给 30 条种子 + 扩展方法。

指标维度：任务质量、结构化输出、业务正确性、工具调用、RAG（Recall@K/MRR/引用准确率）、安全、稳定性、成本、性能（P50/P95）。

初始门槛（需 POC 实测校准）：任务成功率≥90%、草稿字段完整率≥95%、业务规则校验正确率≥98%、工具调用准确率≥95%、引用准确率≥95%、无依据拒答率≥95%、越权拦截率=100%、重复业务写入=0。

**关键原则**：LLM-as-Judge 只辅助评价表达质量；业务规则、权限、数据一致性必须用**确定性断言**（m08 全部是确定性断言）。

可观测性记录：TraceId / ConversationId / TaskId / 模型与 Prompt 版本 / Token / 耗时 / 工具调用 / RAG 来源 / 错误码 / 重试次数 / 状态变化。敏感字段脱敏，不无差别记录完整用户输入、密钥、内部提示词。
