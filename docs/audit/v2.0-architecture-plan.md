# Agent Lab V2.0 架构方案（阶段 B）

> 基于 [阶段 A 审计报告](v2.0-audit-report.md)。核心约束：**知识文档质量优先于数量**。
> 本方案是决策文档，**不含已执行的大规模迁移**；迁移在阶段 C-F 按门禁逐步实施。

---

## 1. 设计原则

1. **渐进式**：保留现有有效资产，不做破坏性重构；迁移保留兼容链接。
2. **质量门禁**：知识主题串行推进（11 试点→验收→12→…），不批量铺薄提纲。
3. **复用优先**：teaching-agent 是质量样板，新内容优先复用其公共层/教材/评测。
4. **五目录各司其职，禁止重复建设**（见 §3）。
5. **可验证**：每个项目可运行 + 有测试；每个评测可复现；成熟度凭证据升级。

## 3. 五目录职责与防重复规则

| 目录 | 职责 | 判定标准 | 禁止 |
|---|---|---|---|
| **docs** | 技术原理/架构/教材 | 「讲懂为什么」 | 放可运行项目主体 |
| **code** | 最小独立实验 | 单知识点、可单独跑 | 放完整工程 |
| **projects** | 完整工程项目 | 有 README/依赖/入口/测试/安全 | 放零散片段 |
| **evals** | 数据集/Benchmark/指标/报告 | 可复现评测 | 各项目私藏评测 |
| **experiments** | 模型/框架/Harness 对比 | 统一配置+存档 | 与 evals 重复 |

**防重复硬规则**：
- 评测数据集/脚本**只在 evals/**，projects 引用而非复制（消除 golden_set/bench 双份）。
- LLM 适配层抽到共享位置，projects 复用（消除 teaching/medical 双份 common/llm.py）。
- 知识教材**只在 docs/**，projects/docs 的通用知识提炼进 docs 并双向链接。
- code 与 projects 不重复实现同一功能；code 是最小验证，projects 是工程集成。

## 4. 知识体系规划（质量门禁串行）

```
11-harness-engineering（试点）
   → §7.6 质量验收 + 用户确认
      → 12-coding-agent → 验收 → 13-ai-software-engineering → 验收
         → 14-agent-runtime → 验收 → 15-agentops
```

- **docs/01-10 升级**：优先核心主题讲透，链接 teaching-agent/docs 现有教材；允许合并/暂缓，不凑数。
- **每主题 README** 必含：学习目标/前置知识/阅读顺序/每章内容/对应代码实验/对应工程项目/学习路径。
- **每章** 按 §7.3 教学结构（问题背景→核心概念→工作原理→架构流程 Mermaid→代码实现→深入分析→工程实践→总结→参考），篇幅 1500–5000 中文字，不填充。
- **验收**：未过 §7.6 清单不得标 Validated。

## 5. 技术选型决策

| 领域 | 决策 | 理由 |
|---|---|---|
| Python Agent 编排 | **LangGraph 1.2**（沿用） | 已验证、活跃、teaching/medical 已用 |
| 多角色协作 | **CrewAI 1.15**（沿用） | 已验证、Healthy |
| 模型接入 | **openai SDK**（OpenAI 兼容，含 DeepSeek/Ollama） | 解耦供应商 |
| Java AI（AI 软件工程项目） | **Spring AI 2.0 + Spring AI Alibaba v1.1.2.2** | 均活跃（审计核实），需 POC |
| Java 图式工作流 | LangGraph4j 1.9.9（候选，POC 后定） | 社区较小，先评估 |
| 工具集成 | **MCP** | 标准化 |
| Coding Agent Harness | 阶段 D 调研定案（候选：自建最小 harness / 现有 coding harness） | 不盲目引入 |
| 评测 | 自建统一 evals + 可选 Ragas/DeepEval | 先自建可控 |
| 可观测 | 阶段 F 接 OpenTelemetry/Langfuse（先结构化日志） | 渐进 |

**不引入**：未经 POC 的新框架；已停止维护的技术（审计未发现）。

## 6. 成熟度模型（凭证据升级）

| 级别 | 含义 | 升级证据 |
|---|---|---|
| **Experimental** | 实验性，未完整验证 | 默认 |
| **Validated** | 通过对应自动化测试 | pytest/selftest 通过 + 质量验收（文档） |
| **Benchmark** | 有可复现评测数据 | evals 可重复运行 + 原始数据存档 |
| **Production-ready** | 具备部署/监控/安全/运维 | CI + tracing + 安全测试 + 运维文档 |

现状：teaching/medical = **Validated（mock）**；无 Benchmark/Production-ready。README 须如实标注。
