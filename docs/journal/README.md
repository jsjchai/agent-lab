# 学习日志

不是日记，是**给未来的自己留的坑位记录**。每次只写三行也行。

## 格式

文件名：`YYYY-MM-DD.md`，一天一个文件（或一次学习一个）。

```markdown
## 2026-11-10 · 手写 ReAct 循环

- 学到：模型不会自己停，停止条件得我自己在循环里判。
- 卡住：工具返回太长，第二轮上下文就爆了。
- 下一步：试试把工具结果截断 + 摘要。
- 相关：code/01-foundations/01_react_loop.py
```

## 规则

- 只记「学到的一个点 / 卡住的一个点 / 下一步」，不写流水账。
- 卡住超过 30 分钟就写下来，避免重复踩同一个坑。
- 一条日志值得展开，就升级成对应主题目录下的正式笔记，日志里留链接。
