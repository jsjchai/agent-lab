# 2026-11-17 · Teaching Agent 落地方法论

把《Teaching Agent 技术知识体系》做成可运行项目 + 可视化 + 评测这一天，沉淀几条可复用的经验。

## 小模型适配：模型负责语义，代码负责边界

- 学到：7B/8B 语义大体对，但**格式必漂移**——槽位键名用中文、`speakers:""`、`speaker_count:"两位"`、
  缺项命名不规范、补充澄清后仍沿用旧日期、RAG 引用加 `chunk_id:` 前缀。
  靠 prompt 喊「请严格」没用，必须在代码里做确定性归一化（清洗类型 + 缺项按必填字段重算 + 日期取最新具体值 + 引用正则提取）。
- 卡住：真实 7B 把补充的「11月20日」仍抽成「下周」，工作流卡在 validation_error。
- 下一步：归一化层用正则取文本最后一个具体日期覆盖；模糊日期视为缺项触发澄清。
- 相关：[m02_intent_slots.py](../../projects/teaching-agent/m02_intent_slots.py)、[m06_rag.py](../../projects/teaching-agent/m06_rag.py)

## 评测：mock 保验收绿，真实模型观察边界

- 学到：mock 是确定性替身，让 `run_all`/m08 稳定全绿；真实模型用来观察能力边界，两者职责分开。
  业务规则/权限/一致性必须确定性断言，LLM-as-Judge 只评表达质量。
- 学到：模型对比要量化「槽位漂移次数」——直观反映格式稳定性。实测 8B 意图 100% 但 13.67s（思考模式），
  7B 87.5% 但 1.62s。**准确率-延迟权衡**正是模型路由（m09）的依据。
- 相关：[m08_eval.py](../../projects/teaching-agent/m08_eval.py)、[m11_model_bench.py](../../projects/teaching-agent/m11_model_bench.py)

## 可视化：交互式工作流用请求/响应，不用 SSE

- 学到：工作流是 interrupt 暂停/恢复的交互流程，start/resume 请求/响应比医疗示例的 SSE 子进程更贴合；
  状态 + 一次性凭证落 SQLite，刷新后按 task_id 恢复（Checkpoint）。
- 卡住：CDP 自动截图时点 `id="tab-eval"` 没切换——那是面板 id，按钮用 `data-tab` 属性；
  fixed-sleep 还有竞态。改用 `querySelector('.tab[data-tab=eval]')` + waitFor 轮询选择器才稳。
- 下一步：前端测试一律用「轮询等待元素出现」，别用固定 sleep。
- 相关：[webui/server.py](../../projects/teaching-agent/webui/server.py)

## 安全：身份与写操作都不能交给模型

- 学到：SecurityContext 来自认证链路，工具参数带 userId/tenantId 即拒绝；Agent 不直接写业务表，
  创建由原业务 API 执行；确认凭证绑定 用户/租户/草稿哈希/有效期 + 一次性消费。12 项安全测试全过。
